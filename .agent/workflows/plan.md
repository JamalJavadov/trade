# Plan Workflow

1. Research the codebase and understand requirements.
2. Develop a proposed approach.
3. You MUST write or update `docs/plan.md` and MUST end with an explicit approval question.
4. The plan must include Status: Draft/Approved, Constraints section, Acceptance Criteria, and Verification Plan.
5. Do NOT implement until approved.
